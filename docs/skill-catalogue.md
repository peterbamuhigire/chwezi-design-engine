# Skill catalogue

The 107 active skills of Chwezi Design Engine, one row each. The table moved here from the repository `README.md` on 2026-10-31 so that the README stays short. Each skill name links to its `SKILL.md`.

The rows were taken from the [107 active `SKILL.md` files listed in the plugin manifest](../.claude-plugin/plugin.json) under `skills/`. The manifest parity check is in [`tests/test_route_existence.py`](../tests/test_route_existence.py). The `_TEMPLATE` scaffold is excluded, and the engine has no `ALIAS.md` entries. The category folders and per-category counts are in the README section "What is inside".

The catalogue is a hint for people. Agents route from the filesystem: they glob `skills/**/SKILL.md` afresh and read each frontmatter `description` (see `AGENTS.md`).
