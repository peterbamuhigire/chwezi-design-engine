# Source Register

This skill distils applicable guidance from the owner's book library. The raw extracted text remains outside the repository and is not committed. The register names each book by its title (and author where the title page gives one). It deliberately records no local file path, file name or acquisition detail: the owner's copy is the evidence, and a public repository carries only the bibliographic identification.

## Substantially Extracted

- *Better Data Visualizations*
  - Used for chart purpose selection, perceptual ranking, preattentive attributes, annotation, legends, clutter removal, chart families, data tables, and visualization style guides.
- *The Production Manual: A Graphic Design Handbook* (required reading range)
  - Used for layout, production constraints, screen color, raster/vector assets, resolution, image saving, typography, alignment, kerning, leading, grids, and handoff quality.
- *Design Elements, Color Fundamentals*
  - Used for color meaning, emotional response, palette structure, value/contrast, dominant/subordinate/accent systems, culture, color as identifier, and color in screen media.
- Jim Krause, *Layout Index: Brochure, Web Design, Poster, Flyer, Advertising, Page Layout, Newsletter, Stationery Index*
  - Used for visual echoes, grids, symmetry/asymmetry, placement, web constraints, load time, cross-platform checks, client voice, and layout exploration.
- *Information Dashboard Design*
  - Used for dashboard purpose, single-screen monitoring, visual perception, dashboard anti-patterns, KPI context, alerting, tables, and business communication.

## Limited Text Extracted

- *How to use graphic design to sell things, explain things, make things look better, make people laugh, make people cry, and (every once in a while) change the world*
- Dennis Puhalla, *Design Elements, Form & Space: A Graphic Style Manual for Understanding Structure and Design*

These two books appeared image-heavy or navigation-only through the text extractor then in use. Their titles and available structure informed the research direction, but detailed operational rules in this skill are grounded primarily in the substantially extracted sources above.

## Copyright Note

The repository stores paraphrased operational guidance, not copied book chapters or long excerpts.
